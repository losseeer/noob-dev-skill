# 原型页面清单

本目录下的内容**不进 schema 校验**，按设计决策由 LLM 直接产出可运行的产物供人工 review。
`current.yaml` 里只登记页面清单与 review 状态（`prototype.pages`），不描述页面内部。

| 页面 | 文件 | 覆盖需求 | review 状态 |
|---|---|---|---|
| 短链生成页 | `index.html` | REQ-001, REQ-003 | pending |

## 怎么打开

直接双击 `index.html`，或用浏览器打开。零构建、无外部依赖、数据存在内存里、刷新即重置。

## review 时看什么

- 创建成功是否给出短码（AC-001）
- 同一个 URL 再提交一次，是否提示复用而不是新生成（AC-002）
- 输入非 http/https，是否给出 `400_INVALID_URL`（IF-001 的错误分支）
- 在跳转模拟框里访问未知短码，是否只报 404 而不重定向（AC-011）
- 每次访问后列表里的点击数是否加一（AC-020）

## 已知留白

错误态目前只表达了 URL 非法一种；网络失败、并发冲突这两类异常的交互表达没有做，等 review 结论决定是否补。
