# 示例输入 · personal_tool

来源：个人博客作者的真实反馈片段（2026-10-01，微信交流）

## 原始输入

> 我在自己那个小博客上加了篇文章收藏，点那个星星按钮没啥反应，
> 也不知道到底成功没有。有时候刷新一下发现又没了。
> 我朋友说他没登录也能看到我收藏的东西，这不应该吧。

## 输入特点

- 没有任何需求工程术语
- 混了三个不同问题：反馈缺失、状态丢失、他人可见
- 没提性能、没提移动端、没提接口

## 期望结果

1. 拆成一条主需求（收藏文章）+ 至少一条隐含需求（收藏可见性权限）
2. 识别出：`feedback`、`permission`、`persistence` 三个维度存在缺口
3. 补完 17 个覆盖维度后生成需求卡，门禁结论 `pass`

## 本目录文件

| 文件 | 说明 |
|---|---|
| `coverage-REQ-001.yaml` | 补齐后的覆盖矩阵，17 维度齐全 |
