# 任务：执行自适应提问

只询问覆盖矩阵中的待问项，使用生活化语言，不要求用户理解架构、合规或运维术语。

## 每轮格式

- 每轮最多 3 题。
- 每题提供 A/B/C 选项；不足三个自然选项时可以只给 A/B。
- 每个选项用一句话说明实际影响。
- 最后提供 `其他（请填写）：______`。
- 对推荐选项明确标注“推荐”，并说明推荐依据。

## 提问规则

1. `conflict`：先列出互相冲突的原始证据，再询问以哪个为准。
2. P0 `missing`：必须询问，不能用默认值绕过。
3. `low_confidence`：只追问一句能区分结果的问题。
4. `undecided`：允许回答“还没想好”；随后采用推荐默认值，并记录触发重审条件。
5. `explicit`、可靠 `inferred` 和已接受默认值：不重复询问。
6. 用户自由文本回答优先于预设选项。

## 回写规则

每轮回答后：

- 更新对应维度的 `status`、`value`、`source`、`reason` 和 `confidence`
- 删除已解决的问题
- 重新执行冲突检测
- 如新答案引入冲突，加入下一轮待问项

## 结束条件

只有以下条件全部满足时才结束：

- 没有 P0 `missing`
- 没有 `conflict`
- 所有 `undecided` 都有用户知情的默认值与复审触发条件
- 所有已检查维度都出现在 `coverage`、`skipped` 或 `defaults_applied` 中

每轮更新后写回 `.project/positioning/coverage.yaml`。输出下一轮问题，或明确输出“覆盖矩阵已满足生成条件”。
